## 第 99 頁：SERVICE BLUEPRINT 01/06｜熟齡藝術參與的完整歷程

從生活觸發到再次創作，將藝術參與視為持續循環的服務歷程。

| 階段 | 歷程 | 內容 | 田野依據 |
|---|---|---|---|
| BEFORE CREATION 創作前 | 01 生活觸發 | 出遊拍照・生活題材 | FIELD：「看到喜歡的景就先拍起來」 |
| | 02 產生意願 | 同伴邀約・固定課程 | OBSERVED：畫友與固定課程成為外部啟動 |
| | 03 準備創作 | 工具・場域 | OBSERVED：小畫本、縮減工具、既有配置 |
| DURING CREATION 創作中 | 04 開始創作 | 構圖・第一筆 | FIELD：「不知道從哪裡下筆」 |
| | 05 持續／卡點 | 水分・比例・技法 | FIELD：「這裡好像畫壞了怎麼辦」 |
| AFTER / LOOP 創作後與循環 | 06 完成作品 | 收整・展示 | OBSERVED：即時成就感與完成感 |
| | 07 分享／回顧 | 家人・畫友交流 | OBSERVED：早安圖與畫友交流 |
| | 08 再次創作 | 回看經驗・參與 | 🔄 LOOP 回 01 |

我們不再只看「畫畫當下」，而是將創作前、中、後與再次參與視為一個連續的服務歷程。

## 第 100 頁：SERVICE BLUEPRINT 02/06｜多元接觸渠道（7 Channels）

從跨場域田野中反覆出現的人、物、環境與互動，歸納藝術參與中的七種接觸渠道。

| Channel | 角色 | 田野來源 |
|---|---|---|
| 01 老師 Instructor | 專業指引・解惑・作品校準 | 是日、禾豆豆、酷妹場域 |
| 02 同伴 Peer | 相約上課・畫友交流・互相激發 | 是日退休學員／畫友網絡 |
| 03 活動 Activity | 主題任務・學習架構・固定參與 | 規律課程與活動提供外部結構 |
| 04 場域 Environment | 家中自在・課堂穩定・戶外受天候影響 | 跨場域觀察 |
| 05 實體工具 Tools | 縮小畫具・自製配置・減少負擔 | 酷妹場域／是日 |
| 06 作品 Artwork | 照片參考・原畫呈現・進入生活 | 是日退休學員 |
| 07 數位 Digital | 尋找參考・LINE 分享・問題紀錄 | 跨場域訪談與觀察 |

七種 Channel 會在不同 Journey 階段進入服務系統，共同形成完整的藝術參與經驗。

## 第 101 頁：SERVICE BLUEPRINT 03/06｜Master Service Blueprint

8 個創作歷程 × 7 個接觸渠道的系統矩陣。（■ Observed Touchpoint／● Design Opportunity，OPP. A–E）

| Channel | 接觸點（依歷程順序） |
|---|---|
| 老師 | 示範第一步 → 卡點解惑（C）→ 後續回饋 |
| 同伴 | 相約邀約（A）→ 同行創作 → 畫友交流 → 再次邀約（E） |
| 活動 | 生活觸發（A）→ 外部啟動 → 任務準備 → 成果展示 → 下次活動 |
| 場域 | 生活場景 → 家／課堂選擇 → 實際創作 → 作品展示 → 再次進入 |
| 工具 | 工具準備（B）→ 實際使用（B）→ 水分／技法支援 → 收整工具 |
| 作品 | 題材照片 → 參考素材 → 完成原畫（D）→ 分享展示（D/E）→ 回看舊作 |
| 數位 | 拍攝素材 → LINE 聯繫 → 手機參考 → 問題紀錄 → LINE 分享（E）→ 回顧紀錄 |

將 Journey 與 Channel 交叉後，可辨識接觸點集中位置，作為後續 Design Opportunity 的系統依據。

## 第 102 頁：SERVICE BLUEPRINT 04/06｜從「想畫」到「開始畫」——準備與卡點形成主要摩擦

放大 Journey 01–05，觀察不同 Channel 如何共同影響創作啟動。

- **OPP. A｜日常啟動（01–02）**
  - Observed：生活照片作題材、固定課程提供外部結構、同伴邀約。
  - Finding：並非每個人都會自主想到「現在來畫畫」，創作需要低壓外部啟動。
- **OPP. B｜工具準備（03–04 × 工具／場域）**
  - Observed：小畫本、縮減工具、自製配置、場域切換。
  - Finding：當工具攜帶與配置需要額外整理時，準備本身成為開始前的摩擦。
- **OPP. C｜卡點支援（05 × 老師／數位）**
  - Observed：水分控制、構圖疑問、自己嘗試、留待下堂課。
  - Finding：卡點後的支援需求不一：有人需即時救急，也有人希望留待下次確認。

**KEY FINDINGS**：01 缺少創作啟動——外部結構或同伴可成為開始契機；02 準備造成摩擦——工具與場域配置影響「想畫」轉為「開始」；03 卡點需求不同——即時協助與延後回饋並存。

前／中段的設計機會主要集中在「啟動 → 工具準備 → 卡點支援」，不同問題不必由同一產品解決。

## 第 103 頁：SERVICE BLUEPRINT 05/06｜作品如何回到生活並形成下一輪觸發

放大 Journey 06–08，觀察作品、關係與回顧如何形成創作循環。

- **06 完成作品（作品 × 場域）**
  - Observed：原畫完成、作品展示、帶回家、即時完成感。
  - Finding：完成本身即形成成就與價值，不需立即導向高強度自主練習。
- **07 分享／回顧（作品 × 同伴 × 數位）**
  - Observed：畫友交流、LINE 分享、家人看到作品、進入日常生活。
  - Finding：作品可能成為家人、畫友與日常關係中的交流媒介。
- **08 再次創作 & RE-ENTRY LOOP 🔄**
  - Observed：回看過去作品、找新題材、再次參與課程、畫友邀約。
  - Loop：回顧過去作品與經驗，形成下一次創作的觸發。

**KEY FINDINGS**：01 即刻成就——作品完成、展示與帶回生活，形成當下完成感；02 關係延伸——作品進入家人與畫友間的分享與交流；03 再次觸發——回看作品與經驗，形成下一輪參與契機。

作品價值不只在「完成」當下；透過生活連結與經驗回看，形成下一次創作的入口。

## 第 104 頁：SERVICE BLUEPRINT 06/06｜服務系統 → 設計介入：篩選與收斂

看見完整系統，不代表每一個接觸點都需要被重新設計。

MASTER SYSTEM（多個機會：啟動、卡點、分享、回顧…）→ Filter Criteria（田野證據／設計必要／系統影響）→

| | 名稱 | 介入類型 | 說明 |
|---|---|---|---|
| CURRENT DIRECTION 01 | 旋展式創作畫板 | PRODUCT｜實體介入（03 → 04） | 聚焦工具攜帶、展開與配置的摩擦，讓創作者更快進入適合自己的狀態。 |
| CURRENT DIRECTION 02 | 日常一畫 Everyday Art | PRODUCT × DIGITAL｜生活介入（01/02/08） | 透過日常微創作觸發，降低「特地開始畫畫」的心理門檻，讓創作嵌入生活。 |
| RESERVED OPPORTUNITIES | 其餘接觸點暫不產品化 | SYSTEM RETAINED｜待後續評估 | 部分問題可由既有老師、課程、LINE 或工具處理；不因藍圖存在接觸點就盲目開發新產品。 |

服務藍圖的目的不是增加產品數量，而是建立完整視角，有依據地選擇值得重新設計的介入點。

## 第 105 頁：CONCEPT 01｜旋展式創作畫板

把生活中「想畫的題材」，轉化成一次容易開始的創作。

- **TARGET PERSONA**：PRIMARY｜B 自在沉浸型；EXTENSION｜A 低壓參與型
- **產品結構**［圖］：中央薄型畫板；左翼為水杯＋調色盤；右翼為筆具收納翼；以低扁旋轉軸連接。左右翼依需求獨立旋開，將用水、調色與筆具配置整合於薄型畫板。CLOSED｜雙翼旋回，薄型攜帶。
- **APP 流程**：01 COLLECT｜採集題材（保存生活中想畫的瞬間）→ 02 CHOOSE｜選擇方式（決定何時、在哪裡、和誰創作：回家畫／上課畫／現地畫）→ 03 FIND & INVITE｜找場域／相約（確認創作條件並邀請熟悉的畫友，例如咖啡館的桌面、座位、水源、遮蔽）→ 04 PREPARE & CREATE｜準備與創作（帶上熟悉畫具，展開即可開始）
- **使用情境**：01 生活採集（日常中發現想畫的題材）→ 02 選擇方式（決定回家畫、上課畫或現地畫）→ 03 尋找場域（找到適合創作的場域）→ 04 展開配置（旋開雙翼，完成用水、調色與筆具配置）→ 05 創作／相約（開始創作，或與畫友相約一起畫）
- **RESEARCH → DESIGN**
  - 現成畫架笨重死板 → 輕量薄型與旋轉軸
  - 工具繁瑣缺乏彈性 → 左右翼獨立旋開配置
  - 場域轉換不易適應 → APP 協助尋找與相約

## 第 106 頁：CONCEPT 02｜習畫問診 PaintClinic

> 本頁為整張圖片，以下為圖中文字整理；頁面右側與底部內容超出版面，部分文字被裁切。

把在家練習時「說不清的卡關」，轉化為課堂上「能被看見與精準對話的進步病歷」。

- **TARGET PERSONA**：PRIMARY｜D 進步校準型；EXTENSION｜C 謹慎防衛型；COLLABORATOR｜課堂授課教師（Instructor）
- **APP SUPPORT｜數位支援架構**
  1. 凍結出錯時空：在家畫錯立即拍照圈記，鎖定第一現場時序，避免後續覆蓋失真。（範例：局部圈選「屋頂透視與山牆陰影濁掉」）
  2. 口語生成提問卡：長輩免打字直接說，自動將零碎口語轉化為結構清晰的專業問題卡。（範例語音：「老師，這老屋透視好像斜掉了，不知道消失點怎麼抓……」→ AI 整理為「建築透視卡點」）
  3. 課堂問診與錄音：課堂出示問題清單，現場同步錄下老師示範口訣，回家點擊局部隨時回放。（CLINIC PASS 已就診，可查看第 2 次修改對比 Recap）
- **THE CLINIC LOGIC｜習畫門診運作機制：告別課堂上「比手畫腳、老師猜謎」的無效溝通**
  學員在家畫作業遇到透視偏斜或水分濁掉時，往往因無法精確描述而硬著頭皮畫完。到課堂時，出錯的第一筆已被覆蓋乾透，長輩只能支吾口述「我那時候畫這邊怪怪的」，老師難以精確診斷。
  1. 還原未乾出錯時空：保留當下手感與猶豫瞬間，老師一眼看懂問題本質，不再憑空猜測。
  2. 教學示範音檔精準錨定：老師點評直接釘選於畫布局部，長輩回家修改時「指到哪、聽到哪」。
  3. 客觀視覺化累積成長：累積個人筆觸進步病歷，滿足進步校準型（Persona D）對實質突破的渴望。
- **使用情境 HOW IT WORKS**（文字部分被裁切）：01 在家作業卡關 → 02 隨手圈記語音 → 03 課堂出示問診 → 04 錄下示範修改

## 第 107 頁：CONCEPT 03｜日常一畫 Everyday Art

把每日撕日曆的習慣，轉化為每天 10–15 分鐘的微創作。

- **TARGET PERSONA**：PRIMARY｜A 低壓參與型；EXTENSION｜B 自在沉浸型；Potential support｜C 謹慎防衛型：步驟引導／創作補救
- **產品**［圖］：木質掛架式日曆（熟悉的日曆形式，承載新的日常）
  - 每日創作紙：日期簡化，大面積留白，保留創作空間。正面為創作區（例：5.14 Wed.「今天，畫一個讓你開心的東西。」）
  - 背面為明信片格式，可以寫下想說的話，寄給重要的人。
  - 內藏創作工具：2–3 色固態水彩、一支水筆、吸水布，打開即可開始創作。
- **APP SUPPORT｜數位支援架構**
  1. 今日靈感：從節氣、生活、主題中獲得畫感，也可以自由選擇。（今日節氣／生活觀察／主題收藏／自由創作）
  2. 跟著畫：提供簡單的步驟教學，也可以選擇「我想自己畫」，依自己的節奏創作。（例：跟著畫桂花，4 個簡單步驟）
  3. 創作支援：拍照提問，獲得修改建議，遇到困難也能繼續完成，不輕易放棄。（「畫壞了怎麼辦？」）
- **使用情境**：01 撕下今天（撕下一張創作紙，開啟今天的小小創作）→ 02 開始畫畫（使用內附的顏料與水筆，或打開 APP 參考教學）→ 03 留下作品（畫完後，可重新插回框架，成為生活中的小風景）→ 04 走進生活（也可以寄成明信片、拍成早安圖分享，讓創作連結你和他人的日常；「一張畫，讓家裡多了一點溫度。」）
- **RESEARCH → DESIGN**
  - 缺少日常創作契機 → 每日撕頁創作
  - 不知道如何開始／卡住 → APP 引導與補救
  - 作品完成後容易被收起 → 展示／分享進入生活
