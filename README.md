# 專案資料｜樂齡繪畫與自主創作研究

本資料夾整理專案的發表簡報、訪談逐字稿與訪談題綱，統一轉為 Markdown（.md）格式，方便 AI 與組員閱讀、搜尋與引用。

> **給 AI 的閱讀說明**
> - `02_訪談逐字稿/` 內為受訪者原話（清稿版），可作為分析與引用的一手資料。
> - 各檔末若有「整理者備註（非訪談原文）」段落，那是研究者的分析筆記，**不是受訪者發言**，引用時請區分。
> - `03_訪談題綱/` 是事先擬好的問題，不是訪談結果。
> - 標記「［……］」為整理者註記，如「［聽不清楚］」表示原錄音無法辨識。

## 研究背景（簡述）

研究關注喜歡藝術、可能固定上繪畫課的樂齡者，如何在課堂外也能持續、自主地創作。訪談涵蓋畫室老師、藝術教育／藝術輔療專業者，以及不同年齡層的學員，議題包括：學畫動機、挫折與成就感、課後自主創作、戶外寫生與畫具、作品分享，以及節氣創作日曆、App／LINE 等設計概念的回饋。

專題名稱：**藝術創齡**——鼓勵高齡者透過創作與社會參與，活化心智、提升晚年生活品質（徐綺廷、陳彰廷）。

研究從「高齡生理限制造成水彩門檻」的假設出發，經 2026 年 8–9 月跨 5 個場域的田野調查後，改以「創作自主度 × 評價包袱」將樂齡創作者分為四型（A 低壓參與型、B 自在沉浸型、C 謹慎防衛型、D 進步校準型），目前發展的概念為生活創作日曆與隨行創作板。詳見 `01_發表/README.md`。
